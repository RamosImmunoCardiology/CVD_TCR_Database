# CVD_TCR_Database
https://ramosimmunocardiology.github.io/CVD_TCR_Database/

We compiled and curated various publicly available high-quality TCR repertoire datasets into a unified Database with the aim to foster integrative analysis across disease models and CDR3 motif discovery. Details of data curation and annotation are described in the reference below.

How to cite our database:
Richter, L., Dias-Ferreira, J., Campos Ramos, G., & Ashour, D. (2026). T Cell Receptor Repertoires Across the Continuum of Vascular, Myocardial, and Age-Related Diseases. Immunological reviews, 339(1), e70125. https://doi.org/10.1111/imr.70125

This resource will be continuously updated as the field progresses.
